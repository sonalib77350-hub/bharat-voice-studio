                Help

                Keys kaise banaye, aur best result kaise milega.

                Sarvam key kaise milegi

                ~₹100 free credit
                1. dashboard.sarvam.ai kholo.
                2. Sign up karo (Google ya email se).
                3. Left menu mein API Keys par jao.
                4. Create (new key) dabao.
                5. Key copy karo.
                6. Yahan API Keys tab mein Sarvam box mein paste karke Save dabao.

                ElevenLabs key kaise milegi

                ~10,000 free credits/mahina
                1. elevenlabs.io kholo.
                2. Sign up karo.
                3. Profile / Developers menu mein jao.
                4. API Keys → Create dabao.
                5. Key copy karke API Keys tab ke ElevenLabs box mein paste karo, Save dabao.

                Best results

                • Chrome browser use karo — live mic aur awaaz sabse achhe chalte hain.
                • Wi-Fi par raho — lambi file aur Whisper model bade hote hain.
                • Mic permission do — address bar ke 🔒 icon → Microphone → Allow.
